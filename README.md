# Carbon-Footprint-Calculator🌴

An interactive web application that explores the environmental impact of network traffic and helps users estimate the carbon footprint associated with their data usage.

The project explains how energy is consumed across data centres, networks, and personal devices, while providing an interactive calculator for estimating environmental impact.

✨ Features

* 🌍 Interactive carbon footprint calculator
* 📊 Data and statistics about internet energy consumption
* 🌱 Information about the environmental impact of network traffic
* 💡 Practical sustainability recommendations
* 📱 Responsive and accessible design
* ⚡ Lightweight front-end application with no backend required

🛠️ Technologies

* HTML5
* CSS3
* JavaScript

🚀 Getting Started

Clone the repository

git clone https://github.com/your-username/carbon-footprint.git
cd carbon-footprint

Run locally

No dependencies or build tools are required.

You can open index.html directly in your browser, or use a local server:

python3 -m http.server 8000

Then open:

http://localhost:8000


🎯 Project Goal

The goal of this project is to make the environmental impact of digital activity easier to understand.

Internet usage may feel invisible, but every search, video stream, download, and cloud service relies on physical infrastructure that consumes electricity. This project visualizes that journey and gives users a simple way to explore their own estimated impact.
